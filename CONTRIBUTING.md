# Contributing

Option Trading is a personal project shared as it is. Issues are welcome: bugs, data sources that stopped working, and corrections to
the Hong Kong contract specifications. For anything bigger than a small fix, **open an issue first** so we can agree on the
direction before you write code; a large pull request that arrives unannounced may be declined, and replies can be slow.

## Set up

Node.js 22 or newer, pnpm 10, PostgreSQL 16. The README has the install steps; the one-minute path that needs no database is
`pnpm install && pnpm demo`.

```bash
pnpm install
cp .env.example .env      # set DATABASE_URL, and PG_ADMIN_URL if you will run the tests
pnpm db:migrate
```

## Before you open a pull request

All four must pass (CI runs the same commands against a `postgres:16` service):

```bash
pnpm lint
pnpm typecheck
pnpm test:web      # UI tests, no database
pnpm test          # needs PostgreSQL through PG_ADMIN_URL; every test file clones a throwaway database
```

`pnpm test:e2e` (the end-to-end scenarios, about four minutes) is not part of CI; run it if you touch the CLI, the ingest path or the
server's security checks.

## Rules the code depends on

- **Skills are pure functions over an as-of-bounded `DataAccess`.** They never read the clock, the environment or the database.
  `tests/structure.test.ts` and the Biome import rules enforce the module boundaries (skills import only `core` and `indicators`;
  only the CLI, the server and the jobs import the providers; nothing but the server imports the server).
- **Fundamentals are point-in-time:** filter by `reported_at`, not `period_end`.
- **Hong Kong is not the US with a different suffix:** the option contract size comes from `data/hk-board-lots.csv` and often differs
  from the stock board lot; expiry is the business day before the last business day of the month.
- **Risk and sizing use the full notional** (strike x multiplier). Margin return is a display number only.
- **The app never places orders.** A change that sends, changes or cancels an order will not be merged.
- **The schema source of truth is `src/db/schema.ts`.** Change it, then `pnpm db:generate`; commit the generated migration. Never edit
  a migration that has already been applied; add a new one.
- **Tests never touch the network.** `tests/helpers/no-network.ts` fails a stray `fetch`; providers are tested against recorded or
  synthetic fixtures. New fixtures must be synthetic or trimmed from public records: no personal data, no copied article text.
- **Indicator golden fixtures are never edited by hand.** They are generated by `tests/fixtures/gen/` (Python and TA-Lib).

## Pull requests

Keep a pull request to one change, say what you ran, and include a test for a bug fix. By contributing you agree that your work is
released under the MIT license of this repository.

## Reporting a vulnerability

Not through a public issue; see [SECURITY.md](SECURITY.md).
